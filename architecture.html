为什么暂不用微信登录？

微信网站登录需要微信开放平台注册 + 网站应用审核（需企业资质），周期较长。先用「学号 + 密码」跑通全流程，数据库预留 openid 字段，后续可平滑接入微信 OAuth。

2数据库设计

共 7 张表，覆盖用户、设备、内存卡、借用申请、操作日志 5 个核心实体。

2.1 users — 用户表

CREATE TABLE users (
  id            INT AUTO_INCREMENT PRIMARY KEY,
  student_id    VARCHAR(20)  NOT NULL UNIQUE COMMENT '学号',
  name          VARCHAR(50)  NOT NULL COMMENT '姓名',
  password_hash VARCHAR(255) NOT NULL COMMENT 'bcrypt 哈希',
  phone         VARCHAR(20)  DEFAULT NULL COMMENT '手机号',
  role          ENUM('user','admin') NOT NULL DEFAULT 'user',
  openid        VARCHAR(64)  DEFAULT NULL COMMENT '微信 openid（预留）',
  avatar_url    VARCHAR(500) DEFAULT NULL,
  is_active     TINYINT(1)   NOT NULL DEFAULT 1,
  created_at    DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at    DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  INDEX idx_student_id (student_id),
  INDEX idx_role (role)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';

2.2 equipment — 设备表

CREATE TABLE equipment (
  id         INT AUTO_INCREMENT PRIMARY KEY,
  code       VARCHAR(20)  NOT NULL UNIQUE COMMENT '设备编号 EQ001',
  name       VARCHAR(100) NOT NULL COMMENT '设备名称',
  category   VARCHAR(50)  NOT NULL COMMENT '类别：相机/镜头/灯光...',
  icon       VARCHAR(10)  DEFAULT '📦',
  image_url  VARCHAR(500) DEFAULT NULL COMMENT '设备图片 URL',
  notes      TEXT         DEFAULT NULL COMMENT '备注/借用限制',
  status     ENUM('available','borrowed','repair') NOT NULL DEFAULT 'available',
  created_at DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  INDEX idx_status (status),
  INDEX idx_category (category)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='设备表';

2.3 cards — 内存卡表

CREATE TABLE cards (
  id         INT AUTO_INCREMENT PRIMARY KEY,
  code       VARCHAR(20)  NOT NULL UNIQUE COMMENT '卡编号 SD001',
  name       VARCHAR(100) NOT NULL COMMENT '卡名称',
  notes      TEXT         DEFAULT NULL,
  status     ENUM('available','borrowed') NOT NULL DEFAULT 'available',
  created_at DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='内存卡表';

2.4 borrow_requests — 借用申请表（核心）

CREATE TABLE borrow_requests (
  id              INT AUTO_INCREMENT PRIMARY KEY,
  work_order_no   VARCHAR(30)  NOT NULL UNIQUE COMMENT '工单号 WO20260717001',
  user_id         INT          NOT NULL COMMENT '借用人 FK→users.id',
  equipment_id    INT          NOT NULL COMMENT '借用设备 FK→equipment.id',
  card_id         INT          DEFAULT NULL COMMENT '配套内存卡 FK→cards.id',
  borrow_time     DATETIME     NOT NULL COMMENT '预计借用时间',
  return_time     DATETIME     NOT NULL COMMENT '预计归还时间',
  actual_return   DATETIME     DEFAULT NULL COMMENT '实际归还时间',
  reason          TEXT         NOT NULL COMMENT '借用理由',
  status          ENUM('pending','approved','borrowing',
                       'return_pending','returned',
                       'rejected','cancelled') NOT NULL DEFAULT 'pending',
  approver_id     INT          DEFAULT NULL COMMENT '审批人 FK→users.id',
  admin_comment   TEXT         DEFAULT NULL COMMENT '审批备注',
  return_photo_url VARCHAR(500) DEFAULT NULL COMMENT '归还照片 URL',
  created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  INDEX idx_user (user_id),
  INDEX idx_equipment (equipment_id),
  INDEX idx_card (card_id),
  INDEX idx_status (status),
  INDEX idx_borrow_time (borrow_time),
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE RESTRICT,
  FOREIGN KEY (equipment_id) REFERENCES equipment(id) ON DELETE RESTRICT,
  FOREIGN KEY (card_id) REFERENCES cards(id) ON DELETE SET NULL,
  FOREIGN KEY (approver_id) REFERENCES users(id) ON DELETE SET NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='借用申请表';

2.5 operation_logs — 操作日志表

CREATE TABLE operation_logs (
  id          INT AUTO_INCREMENT PRIMARY KEY,
  actor_id    INT          NOT NULL COMMENT '操作人 FK→users.id',
  action      VARCHAR(30)  NOT NULL COMMENT '操作类型',
  detail      TEXT         NOT NULL COMMENT '操作详情',
  target_type VARCHAR(20)  DEFAULT NULL COMMENT '目标类型 request/equipment/card',
  target_id   INT          DEFAULT NULL COMMENT '目标 ID',
  ip_address  VARCHAR(45)  DEFAULT NULL,
  created_at  DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_actor (actor_id),
  INDEX idx_action (action),
  INDEX idx_target (target_type, target_id),
  INDEX idx_created (created_at),
  FOREIGN KEY (actor_id) REFERENCES users(id) ON DELETE RESTRICT
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='操作日志表';

2.6 refresh_tokens — 刷新令牌表

CREATE TABLE refresh_tokens (
  id          INT AUTO_INCREMENT PRIMARY KEY,
  user_id     INT          NOT NULL,
  token_hash  VARCHAR(255) NOT NULL UNIQUE COMMENT 'SHA256 哈希',
  expires_at  DATETIME     NOT NULL,
  created_at  DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  is_revoked  TINYINT(1)   NOT NULL DEFAULT 0,
  INDEX idx_user (user_id),
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='刷新令牌表';

2.7 system_config — 系统配置表

CREATE TABLE system_config (
  id    INT AUTO_INCREMENT PRIMARY KEY,
  key   VARCHAR(50) NOT NULL UNIQUE,
  value TEXT        NOT NULL,
  desc  VARCHAR(200) DEFAULT NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='系统配置表';

设计要点：

1. 外键约束保证数据完整性，设备被借用时无法删除

2. ON DELETE SET NULL 用于 card_id/approver_id，删卡/删审批人后请求记录保留

3. 状态用 ENUM 而非 VARCHAR，确保值域安全

4. 关键查询字段加索引（user_id / status / borrow_time）

3RESTful API 接口文档

所有接口前缀 /api/v1，返回 JSON 格式 { "code": 0, "data": {...}, "message": "ok" }。需认证的接口在 Header 携带 Authorization: Bearer <jwt>。

3.1 认证模块

方法路径说明认证
POST/auth/login学号 + 密码登录，返回 access_token + refresh_token否
POST/auth/refresh刷新 access_token否
POST/auth/logout登出，吊销 refresh_token是
GET/auth/me获取当前登录用户信息是
PUT/auth/password修改密码是

3.2 设备模块

方法路径说明权限
GET/equipment设备列表（支持 ?status=&category=&keyword= 筛选）所有用户
GET/equipment/{id}设备详情 + 时间轴借用记录所有用户
POST/equipment添加设备管理员
PUT/equipment/{id}编辑设备管理员
DELETE/equipment/{id}删除设备（有活跃借用时拒绝）管理员
PATCH/equipment/{id}/status切换设备状态（设为维修/可用）管理员
POST/equipment/{id}/image上传设备图片（multipart）管理员

3.3 内存卡模块

方法路径说明权限
GET/cards内存卡列表（支持 ?status= 筛选）所有用户
POST/cards添加内存卡管理员
PUT/cards/{id}编辑内存卡管理员
DELETE/cards/{id}删除内存卡（有活跃借用时拒绝）管理员

3.4 借用申请模块（核心）

方法路径说明权限
GET/requests借用记录列表（?status=&keyword= 筛选，普通用户只看自己的）是
GET/requests/{id}借用记录详情是
POST/requests提交借用申请（含冲突检测）是
DELETE/requests/{id}取消/删除申请（pending 状态用户可取消）是
POST/requests/{id}/return提交归还（上传归还照片，状态→return_pending）是
POST/requests/check-conflict实时冲突检测（借用表单中选择设备/时间后调用）是

3.5 审批模块（管理员）

方法路径说明权限
GET/admin/requests/pending待审批列表（统计卡片数据）管理员
POST/admin/requests/{id}/approve审批通过（含维修状态检查 + 冲突复查）管理员
POST/admin/requests/{id}/reject拒绝申请（含拒绝理由）管理员
POST/admin/requests/{id}/pickup确认领取（可选配内存卡，状态→borrowing）管理员
POST/admin/requests/{id}/confirm-return确认归还完成（释放内存卡，状态→returned）管理员
GET/admin/stats仪表盘统计（待审核/借用中/待归还/总数）管理员

3.6 操作日志模块

方法路径说明权限
GET/admin/logs操作日志列表（?action=&actor=&page=&size= 分页）管理员

router.beforeEach((to, from, next) => {
  const auth = useAuthStore()
  if (to.meta.auth && !auth.isLoggedIn) return next('/login')
  if (to.meta.admin && !auth.isAdmin) return next('/')
  if (to.meta.guest && auth.isLoggedIn) return next('/')
  next()
})

Axios 拦截器（核心）

// api/request.ts
const instance = axios.create({ baseURL: '/api/v1', timeout: 10000 })

// 请求拦截：自动注入 JWT
instance.interceptors.request.use(config => {
  const token = localStorage.getItem('access_token')
  if (token) config.headers.Authorization = `Bearer ${token}`
  return config
})

// 响应拦截：401 自动刷新 token，403 权限提示
instance.interceptors.response.use(
  res => res.data,
  async error => {
    if (error.response?.status === 401) {
      const refreshed = await tryRefreshToken()
      if (refreshed) return instance(error.config) // 重试
      redirectToLogin()
    }
    return Promise.reject(error)
  }
)

Nginx 配置

# nginx/nginx.conf
server {
    listen 80;
    server_name your-domain.com;
    # HTTPS 重定向
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    server_name your-domain.com;

    ssl_certificate     /etc/nginx/ssl/cert.pem;
    ssl_certificate_key /etc/nginx/ssl/key.pem;

    # Vue 前端静态文件
    location / {
        root /usr/share/nginx/html;
        try_files $uri $uri/ /index.html;  # SPA 路由回退
    }

    # API 反向代理 → FastAPI
    location /api/ {
        proxy_pass http://backend:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # 上传文件访问
    location /uploads/ {
        alias /var/www/uploads/;
        expires 30d;
    }

    # 文件上传大小限制
    client_max_body_size 10M;
}

# 迁移脚本 (Python)

python scripts/migrate_from_json.py backup.json

# 脚本逻辑：
#   - users:     从 eb_users 数组插入 users 表
#   - equipment: 从 eb_equipment 映射字段插入 equipment 表
#   - cards:     从 eb_cards 映射插入 cards 表
#   - requests:  从 eb_requests 映射 status/字段插入 borrow_requests 表
#   - logs:      从 eb_logs 映射插入 operation_logs 表

迁移注意事项：

1. 用户密码需要重置（单机版是明文，全栈版用 bcrypt），首次登录时强制改密

2. 图片从 Base64 迁移为文件 URL（存到 /uploads/ 目录）

3. 时间格式统一为 ISO 8601（单机版部分时间格式不一致）

4. 工单号生成规则保持一致，避免迁移后冲突

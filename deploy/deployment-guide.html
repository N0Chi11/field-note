1上传项目到服务器

在你的本地电脑（Windows）打开 PowerShell，执行以下命令将项目打包上传：

# 1. 在本地打包项目（排除 node_modules）
cd D:\equipment-system
tar -czf equipment-system.tar.gz --exclude=node_modules --exclude=.git --exclude=__pycache__ --exclude=*.pyc .

# 2. 上传到服务器（替换 root 为你的用户名）
scp equipment-system.tar.gz root@47.116.101.102:/root/

# 3. SSH 登录服务器
ssh root@47.116.101.102

# 4. 在服务器上解压
cd /root
mkdir -p equipment-system
tar -xzf equipment-system.tar.gz -C equipment-system
cd equipment-system

如果你不知道 SSH 密码

阿里云控制台 → ECS 实例 → 重置实例密码 → 重启实例

或使用阿里云的「远程连接」功能直接在浏览器里操作终端

2修改配置文件密码

解压后，先修改 .env 文件中的密码（很重要！）：

# 复制生产配置模板
cp deploy/.env.prod .env

# 编辑配置文件
vi .env

# 按 i 进入编辑模式，修改以下内容：
# MYSQL_ROOT_PASSWORD=你的root密码
# MYSQL_PASSWORD=你的应用密码
# JWT_SECRET=按 ESC 后执行 :!openssl rand -hex 32 生成随机密钥
# CORS_ORIGINS=http://47.116.101.102,https://47.116.101.102

# 修改完按 ESC，输入 :wq 保存退出

必须修改的项

1. MYSQL_ROOT_PASSWORD 和 MYSQL_PASSWORD — 数据库密码

2. JWT_SECRET — 生成命令：openssl rand -hex 32

3. DATABASE_URL 中的密码要和 MYSQL_PASSWORD 一致

3运行一键部署脚本

# 赋予执行权限
chmod +x deploy/deploy.sh

# 运行部署脚本
./deploy/deploy.sh

4配置阿里云安全组

如果访问不了，需要在阿里云控制台开放端口：

  1. 登录 阿里云控制台 → ECS → 实例
  2. 找到你的服务器实例，点击实例 ID
  3. 左侧菜单 → 安全组 → 点击安全组 ID
  4. 点击 入方向 → 手动添加
  5. 添加两条规则：
方向端口范围授权对象说明
入方向80/800.0.0.0/0HTTP 访问
入方向443/4430.0.0.0/0HTTPS 访问

不需要开放 3306 和 6379 — 数据库和 Redis 只在 Docker 内部网络通信，不对外暴露

常用运维命令

# 查看服务状态
docker compose -f docker-compose.prod.yml ps

# 查看后端日志（实时）
docker compose -f docker-compose.prod.yml logs -f backend

# 查看所有日志
docker compose -f docker-compose.prod.yml logs -f

# 重启某个服务
docker compose -f docker-compose.prod.yml restart backend

# 停止所有服务
docker compose -f docker-compose.prod.yml down

# 重新构建并启动（更新代码后）
docker compose -f docker-compose.prod.yml up -d --build

# 进入数据库
docker exec -it equip-mysql mysql -u equip_app -p equipment_db

# 查看数据库数据
docker exec -it equip-mysql mysql -u root -p -e "SELECT * FROM equipment_db.equipment;"

更新代码后重新部署

# 1. 本地修改代码后重新打包
cd D:\equipment-system
tar -czf equipment-system.tar.gz --exclude=node_modules --exclude=.git .

# 2. 如果前端有改动，先本地构建
cd frontend && npm run build && cd ..

# 3. 上传到服务器
scp equipment-system.tar.gz root@47.116.101.102:/root/equipment-system/

# 4. SSH 登录，解压并重启
ssh root@47.116.101.102
cd /root/equipment-system
tar -xzf equipment-system.tar.gz
docker compose -f docker-compose.prod.yml up -d --build

数据库不会丢失 — Docker 数据卷 mysql_data 和 redis_data 在重启后保留。只有 docker compose down -v（带 -v 参数）才会删除数据。

故障排查

访问不了网站

1. 检查安全组是否开放 80/443 端口

2. 检查 Nginx 容器是否运行：docker ps | grep nginx

3. 检查防火墙：firewall-cmd --list-ports 或 ufw status

API 报 500 错误

1. 查看后端日志：docker compose -f docker-compose.prod.yml logs backend

2. 检查数据库连接：确认 .env 中的密码与 MYSQL_PASSWORD 一致

3. 检查数据库是否初始化：docker exec equip-mysql mysql -u root -p -e "SHOW DATABASES;"

登录失败

1. 确认用户表有数据：docker exec equip-mysql mysql -u equip_app -p equipment_db -e "SELECT id,student_id,name,role FROM users;"

2. 默认密码是 admin123，如果修改过 init.sql 中的哈希需要重新生成

HTTPS 证书警告

自签名证书浏览器会警告，这是正常的。点击「高级」→「继续前往」即可。

如果有域名 + 备案，可以用 Let's Encrypt 申请免费证书替换 deploy/ssl/ 下的文件。

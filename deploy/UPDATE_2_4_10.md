# FIELD NOTE v2.4.10

- 优化预约日历的冬日画报样式与手机布局，支持按日期查看全部预约、查看详情并发起借用。
- 美化器材清单的搜索区域和设备卡片，以及借用申请页的说明、表单和冬日装饰。
- 为器材、操作和导航设计统一的覆雪冬日图标。
- 日历按北京时间划分日期，快速切换月份时忽略过期响应；加载失败时提供重试，不再显示为空预约。
- 从日历选择的默认时段已过去时，借用表单会明确提示已调整到明天。
- 时间轴使用设备本身的状态，避免把维修中或已借出设备误显示为可借用，并避免切换设备时展示过期数据。
- 个人中心的借用统计只计算当前用户的记录；加载失败提供重试。
- 本次不改变后端、数据库或已有借用数据。

## 服务器轻量更新

```bash
cd /root/equipment-system && git pull --ff-only origin main && (cd frontend && npm run build)
```

构建成功后强制刷新浏览器；这次不需要重新下载或构建 Docker 镜像。此前未成功部署的后端改动仍需另行部署。

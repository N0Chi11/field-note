# FIELD NOTE v2.4.4

- 照片审核工作区按管理员账号隔离。每个账号只会读取自己的照片、预览、人脸裁剪、任务状态、审核设置、缓存和导出；接口按当前登录会话选择对应工作区。
- “新批次”、停止审核、合并/拆分、人工标记和导出均只作用于当前管理员的数据。

不改借用系统业务表，无需数据库迁移。更新命令：

```bash
cd /root/equipment-system
bash deploy/quick-update.sh
```

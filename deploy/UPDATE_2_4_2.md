# FIELD NOTE v2.4.2

- 管理员导航新增“照片审核”，接入《你拍的照片怎么样》0.2.2 最新人工核对规则。
- 照片审核与主后端分容器、分持久卷；所有入口、接口与预览均要求管理员短期会话。照片容器不开放公网端口，也不持有主系统登录 JWT 密钥。
- 统一为 FIELD NOTE 纸感、衬线标题、靛蓝强调色与细分隔线；移除服务器端不可用的“选择文件夹”，支持浏览器多选照片上传。
- 新批次会清除该工具的服务器照片副本、预览、导出临时文件及审核缓存；本机原图不受影响。联网审核仍需管理员主动点击，API Key 只保存在当前进程内存。

不改借用业务数据表，不需要数据库迁移。已有 ECS 用 `bash deploy/quick-update.sh` 部署；脚本在旧 `.env` 缺少 `PHOTO_REVIEW_SESSION_SECRET` 时会生成独立随机密钥，再构建前端、后端和照片服务并重启 Nginx。

照片上传会把副本发送到 ECS。现有站点若仍通过 HTTP 使用，请先配置有效 HTTPS 再处理真实活动照片。
